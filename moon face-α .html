方法B：inferencejs（端末内TensorFlow.js）ブラウザサンプル

inferencejs（内部はTensorFlow.js）でブラウザ上に学習済みモデルを読み込み、画像/カメラで物体検出を試すための簡易ツールです。

再学習は不要です（2026-08-28 時点の最新情報で更新）。
Roboflow の現行ドキュメントでは、inferencejs の対応モデルは RF-DETR ／ Roboflow 3.0（YOLOv8互換）／ YOLOv5 ／ YOLOLite です。 いま学習済みの Roboflow 3.0 のまま端末内実行できます。
6月にご案内した「YOLO Lite で再学習が必要」は、当時使っていた inferencejs 1.0.11（旧版）での 判定でした。このページは最新の 1.3.0 に更新しています。
動作確認：Roboflow公式サンプルと同じ公開デモモデル（coco 版3）を このページと同じ構成で読み込み、推論まで通ることを確認済みです（読込 約12秒）。 つまりページ側・ライブラリ側は正常に動きます。

① モデル設定

Roboflow → Settings → API Keys の「Publishable」キー（方法Aで使う Private キーとは別物です）
Roboflow左メニューの Models に出ている ID: mikan-thinning/2 を スラッシュで分けて入力します（slug＝mikan-thinning、版＝2）。 Deploy の操作は不要です。 ※ブレインにて、Roboflow公式サンプルと同じ公開デモモデルでこの方式の動作を確認済みです。
新形式の {workspace}/{model-slug} 形式のIDを持つモデル用です。 mikan-thinning/2 のような「slug／版」形式のIDでは、こちらは使えません （上の推奨方式をお使いください）。
